# Vite

ite (French for "quick", pronounced /vit/) is a modern frontend build tool that provides an extremely fast development environment and optimized production builds. Created by Evan You (creator of Vue.js), it replaces traditional bundlers like Webpack, using native ES modules and esbuild to enable near-instant server starts and lightning-fast Hot Module Replacement (HMR).

Create a bare-metal version of Vite:

```bash
npm create vite@latest my-uni --template vanilla

```
